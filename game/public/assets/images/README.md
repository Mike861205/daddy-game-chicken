# Imágenes del juego

Coloca aquí tus imágenes reales (formato PNG o WebP). El juego usa
placeholders automáticos cuando una imagen no existe, así que nunca se
romperá si falta un archivo.

## Recomendaciones

- Tamaño sugerido: 96x96 a 256x256 px, fondo transparente.
- Optimiza el peso. Prefiere WebP cuando sea posible.
- Mantén los nombres exactamente como arriba (minúsculas, con guiones).
