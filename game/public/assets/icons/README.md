# Icono de la PWA

Reemplaza únicamente `daddy-pollo-pwa.png` con el logo definitivo de la app.

- Usa una imagen PNG cuadrada, preferentemente de 1024 × 1024 px.
- Mantén el contenido principal centrado y con margen para que no se corte en
  los iconos circulares de Android.
- Conserva exactamente el nombre `daddy-pollo-pwa.png`.

Al iniciar Vite o ejecutar el build se generan automáticamente las versiones
`daddy-pollo-pwa-192.png` y `daddy-pollo-pwa-512.png` utilizadas por Android,
iOS y el instalador.
